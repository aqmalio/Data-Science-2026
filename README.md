## Tools & Library

*   **Python 3:** Bahasa pemrograman.
*   **Pandas:** Manipulasi dan analisis data *tabular* (Dataframe).
*   **NumPy:** Untuk komputasi numerik dan operasi *array*.
*   **SciPy:** Digunakan untuk komputasi saintifik dan perhitungan statistik teknis yang lebih kompleks.
*   **scikit-learn:** *Library* utama untuk memanggil algoritma *Machine Learning* (Regresi Linear, Logistik, Klasifikasi, Clustering, dll).
*   **Matplotlib & Seaborn:** Untuk visualisasi data, bikin grafik, dan nge-plot matriks.
*   **TensorFlow & Keras:** Untuk membangun Neural Network dan Deep Learning.
*   **mlxtend:** Untuk Market Basket Analysis (Apriori & Association Rules).


## Kesimpulan Umum Belajar Data Science (Pertemuan 1 - 13)

Perjalanan belajar Data Science dari Pertemuan 1 hingga 13 memberikan saya pemahaman menyeluruh tentang lifecycle data science: dari preparasi dan cleaning data (Pertemuan 1-6), supervised learning seperti regresi dan klasifikasi (Pertemuan 7, 9-10), hingga advanced topics seperti clustering, market basket analysis, dan deep learning (Pertemuan 11-13). Saya menyadari bahwa **data quality adalah fondasi**, dan memilih metrik evaluasi yang tepat berdasarkan domain problem jauh lebih penting daripada sekadar mengejar akurasi tertinggi.

Melalui studi kasus praktis—deteksi kanker payudara, prediksi churn pelanggan, segmentasi pelanggan, dan analisis sentimen—saya belajar bahwa tidak ada satu algoritma untuk semua masalah. Setiap masalah memerlukan pemilihan teknik yang berbeda: apakah supervised atau unsupervised, linear atau non-linear, dan bagaimana preprocessing serta feature engineering sangat mempengaruhi performa akhir model.

Ke depannya, saya akan mengintegrasikan model-model analitik ini ke dalam arsitektur backend yang saya bangun, mempelajari MLOps untuk deployment, dan mengeksplorasi lebih dalam tentang interpretability serta time-series forecasting. Dengan cara ini, aplikasi yang saya kembangkan tidak hanya fungsional, tetapi juga **data-driven dan mampu belajar dari pengalaman**.
